A local alternative to GitHub Copilot cloud agent

Rusuban is a free, MIT-licensed alternative to GitHub Copilot cloud agent, formerly called Copilot coding agent. Both take GitHub work off your hands and open pull requests. Copilot cloud agent works on a task you give it, in a cloud environment, and cannot merge its own pull request. Rusuban runs Claude Code on your own machine, reads every issue and pull request, judges each one against the rules in your repo, and merges what those rules allow behind its locks. Copilot cloud agent is the better choice when your team works in GitHub's interface and wants no machine of its own to run.

This page is published by the Rusuban project. The details on Copilot cloud agent come from GitHub's documentation, plans page and changelog, checked in November 2026. GitHub renamed and repriced Copilot several times in 2026. The sources are listed at the end.

What both do

  • From an issue to a pull request. A Rusuban worker fixes a bug and opens the PR. Copilot cloud agent works on its branch and opens one too.
  • Work kept apart. Rusuban's workers use worktrees of its own clone, never your checkout. Copilot works on a branch of its own.
  • People keep the merge, or set its terms. Copilot's agent never approves or merges its own work. Rusuban's agents never merge: its server does, only where your rules and its locks allow.

Where Rusuban differs

Nobody has to assign it

Rusuban reads every issue, PR, review and CI run, and a judge decides what each one needs, as your rules say. You do not pick tasks for it: you write once what it may do alone and what comes to you. See issue and PR triage.

Rules you can read

The rules are Markdown files in your repo, on its default branch. They say which pull requests may merge without a person, how long a third party is waited for, and how agents write on GitHub. See Writing rules.

Merges behind locks

When your rules let a pull request merge alone, Rusuban's server merges it once eight gates pass on the head it checked, with your path and size locks among them. See auto-merge behind locks.

Your machine, your Claude plan

The agents run where your tools and test machines are, on the Claude plan you already pay for, within its limits. Rusuban adds no credits and no minutes. Its code is open, under the MIT license.

One inbox for your decisions

What your rules keep for you comes as a card, in one inbox for all your projects, answered in the dashboard or on your phone.

When Copilot cloud agent is the better choice

  • Your whole team hands it tasks, from issues, pull requests, IDEs, Slack or Teams. A Rusuban instance is one person's.
  • You keep no machine on. It runs in GitHub's cloud.
  • You need models other than Claude. It offers models from several vendors.

Getting started

  1. Install Rusuban: npm install -g rusuban, then rusuban init. You need Node 22 or later, and gh and Claude Code logged in.
  2. Write your first rules, or start from an example.
  3. Keep merges paused while you read the first judgments.

Comparing other tools as well? See Rusuban vs Claude Code GitHub Actions and Rusuban vs Mergify.
