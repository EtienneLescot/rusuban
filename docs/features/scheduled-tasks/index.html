Run Claude Code tasks on a schedule

A Rusuban task is a text file: a few lines of front matter, then a prompt. Rusuban runs it with Claude Code, headless, at the times you set or when you click, and keeps every run in its dashboard.

A task file

---
title: Evening summary
project: widgets
schedule: daily 18:30
---
Sum up what merged today in owner/widgets and what still waits
for a review, in five lines at most.
FieldWhat it does
titleThe task's name in the dashboard
projectThe project the task belongs to, a project without a repo included
scheduledaily HH:MM, or several times, as daily 09:00,17:30. Without it, the task runs on a click
lockOptional. Tasks and runs that share a lock run one at a time
cwdOptional. The folder the task runs in, the project's scratch folder by default

Add and run it

rusuban task add evening-summary.md
rusuban task list
rusuban task run <id>

A task is your request, so adding or changing one waits for your yes: you type it in a terminal, or answer a card when Claude Code made the change. rusuban task remove <id> removes one.

You can also ask Claude Code in your own words, through Rusuban's MCP server: "write a task that drafts the release notes every morning". See Setting Rusuban up from Claude.

How it runs

  • On your machine, as a headless claude -p session, on the model you chose and under your host profile.
  • Within your project's rules and the safety frame every run gets.
  • At its times. A time missed while the service was down runs once when it is back.
  • One at a time with the tasks and runs that share its lock.
  • In the dashboard. Each run shows with its final answer and its conversation. A decision a person must take about an item comes to you as a card.

Tasks about no repo

A task does not have to be about a repo. Put it in a project without one:

rusuban project create publications --title Publications

Then give each task project: publications. The project's page shows its tasks, runs and conversations, and nothing is read, judged or merged on GitHub for it.

Compared with cron

You can run claude -p from cron. A Rusuban task adds what cron does not know about: the time missed while the machine was off, the lock that keeps two runs off the same work, your rules and the safety frame in the prompt, and a dashboard that keeps each run and its conversation.

Get started

  1. Install Rusuban.
  2. Write a task file, then rusuban task add it.
  3. Click it once in the dashboard to see its first run.
